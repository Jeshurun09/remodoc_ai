## Quick Start

### 1. Database Migration

Apply all new schema changes to your database:

```bash

# Create migration

npx prisma db push
```

## Performance Optimization

### 1. Database Indexes

All critical queries have indexes. Verify:

```sql
-- Check indexes in MongoDB
db.TriageQueue.getIndexes()
db.DoctorAvailability.getIndexes()
db.HealthTimeline.getIndexes()
```

### 2. Caching Strategy

Consider adding Redis for high-traffic endpoints:

```typescript
// lib/cache.ts
import Redis from 'redis';

const redis = Redis.createClient();

export async function getCachedDoctors(key: string) {
  const cached = await redis.get(key);
  if (cached) return JSON.parse(cached);
  
  // Fetch from DB
  const doctors = await prisma.doctorAvailability.findMany({...});
  
  // Cache for 5 minutes
  await redis.setex(key, 300, JSON.stringify(doctors));
  return doctors;
}
```

### 3. Query Optimization

Example optimizations already applied:

```typescript
// ✓ Select only needed fields
const doctors = await prisma.doctorAvailability.findMany({
  select: {
    doctorId: true,
    isOnline: true,
    currentlyAvailable: true,
    waitingTime: true,
  }
});

// ✓ Use pagination
const page = parseInt(req.query.page) || 1;
const skip = (page - 1) * 50;
const events = await prisma.healthTimeline.findMany({
  skip,
  take: 50,
  orderBy: { date: 'desc' }
});

// ✓ Filter at database level
const triage = await prisma.triageQueue.findMany({
  where: {
    status: 'PENDING',
    urgencyLevel: 'CRITICAL'
  }
});
```

## Monitoring & Logging

### 1. System Health Monitoring

Create a cron job to record metrics:

```typescript
// scripts/monitor-health.ts
import { prisma } from '@/lib/prisma';

async function recordMetrics() {
  const totalUsers = await prisma.user.count();
  const onlineDoctors = await prisma.doctorAvailability.count({
    where: { isOnline: true }
  });
  
  await prisma.systemHealthMetric.create({
    data: {
      metricName: 'total_users',
      metricValue: totalUsers,
      status: 'healthy'
    }
  });
  
  // Record more metrics...
}

// Schedule: every 5 minutes
// node -r ts-node/register scripts/monitor-health.ts
```

### 2. Alert System

Set up critical alerts:

```typescript
// Send alert if critical triage pending
async function checkCriticalCases() {
  const criticalCount = await prisma.triageQueue.count({
    where: { urgencyLevel: 'CRITICAL', status: 'PENDING' }
  });
  
  if (criticalCount > 0) {
    // Send Slack/email alert
    await sendAlert(`${criticalCount} critical cases pending`);
  }
}
```

## Troubleshooting

### Common Issues

#### 1. Prisma Migration Fails
```bash
# Reset database (development only!)
npx prisma migrate reset

# Or manually check schema
npx prisma validate
```

#### 2. Triage Not Working
- Check that symptom report was created first
- Verify symptom report ID is correct
- Check server logs for AI API errors

#### 3. Doctor Availability Empty
- Ensure doctors exist in database
- Check that doctor availability records are being created
- Verify doctor's `isOnline` status

#### 4. AI Features Returning Errors
- Check GOOGLE_GEMINI_API_KEY is set
- Verify API key has correct permissions
- Check API quota limits

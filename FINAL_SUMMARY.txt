 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Add environment variables:
   STRIPE_SECRET_KEY, PAYPAL_CLIENT_ID, MPESA_CONSUMER_KEY, etc.

2. Update database:
   npx prisma generate
   npx prisma db push

3. Run tests:
   npx ts-node scripts/tests/e2e_tests.ts

4. Calculate payouts:
   npx ts-node scripts/calc_payouts.ts
